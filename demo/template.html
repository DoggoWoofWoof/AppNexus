Try the demo
  1. Open Plan my day, inspect or select sample people, then review the day.
  2. Edit a visit: leave it flexible or choose a planned time. Confirmation is an explicit choice.
  3. Open the map from Today or switch between Map and List in Targets.
  4. Prepare from a profile, then log a visit, enter a note and add a follow-up.
  5. Review or edit the conversation in Activity and complete the linked follow-up.
  6. Explore the profile section index and the named tools in Insights.

Plans and notes stay in this page's memory and disappear on refresh. No production API, CRM, report, routing or backup service is connected. Map geography is real; people, assignments and activity are illustrative.
